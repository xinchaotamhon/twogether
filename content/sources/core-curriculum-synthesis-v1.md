# Core curriculum synthesis v1

> Superseded on 2026-08-25 by `core-curriculum-synthesis-v2.md`. This predecessor remains for provenance; do not use its 20-English-card scope as the current contract.

This is a project-owned curriculum synthesis, not a raw Claude capture and not a claim that it contains every fact in English or React. It uses the two owner-pasted Claude captures as the conceptual spine, then adds a small number of standard prerequisite concepts so a learner can move from principle to mechanism, boundary, and transfer.

## Learning invariant

Every card belongs to one of four rungs:

1. principle — state the generative rule;
2. mechanism — explain why the rule produces an observable result;
3. boundary — identify where the shortcut stops working or needs qualification;
4. transfer — use the rule in a fresh example.

The initial 20 English and 10 React cards are a compact core starter, not an exhaustive “everything” list. English has unlimited lexical and contextual branches; React has version-sensitive implementation details. New branches must attach to a prerequisite and preserve this ladder.

## Scope of the 30 drafts

- English: sentence skeleton, verb/auxiliary system, word order, agreement, time × aspect, root-versus-lexicalized branches, pronunciation rhythm, collocation, and transfer.
- React: snapshot state, pure render, derived description, identity/reconciliation, keys/types, Hook call-order, functional updates, effects, and the public-vs-internal boundary around Fiber.

## Promotion rule

All cards remain `draft`. Human review must check learner level, examples, technical version scope, and whether the model answer is bounded enough for honest self-grading. Do not load this file into the P0 runtime until the project owner approves a reviewed subset.
